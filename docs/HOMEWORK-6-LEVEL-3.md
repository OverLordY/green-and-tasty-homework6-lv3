# ДЗ №6: Owner групового pre-order — рівень 3

## Реалізовано

- Підключено адресу API Gateway в `environment.development.ts`; `?demo` продовжує працювати на моках.
- Owner-токен передається для захищених запитів `/guest/groups/...`, а звичайні гостьові запити не отримують токен Owner.
- Екран показує актуальні замовлення, статус і підсумок лише підтверджених кошиків; підтримує Submit та бонусне видалення гостя.
- Поки група відкрита, дані синхронізуються кожні 15 секунд або кнопкою Refresh. Фонові помилки не прибирають останні дані та не створюють зайвих toast-сповіщень.

## Межі реалізації

Початковий архів не містить повного серверного застосунку. Наявний окремий Backend реалізує Owner API, але не реалізує штатні сценарії реєстрації/входу через `/signin`, створення бронювання та самостійного оформлення кошика гостем. У live-перевірці використано тестову групу, створену в DynamoDB, та тестового користувача Cognito. Тому повний наскрізний сценарій із реєстрацією, бронюванням і запрошеним гостем ще не перевірено і не слід заявляти його завершеним.

Скриншоти в `docs/screenshots/` зроблені раніше для демо-режиму; вони не є доказом live-перевірки.
